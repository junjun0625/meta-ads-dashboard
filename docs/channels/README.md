## 全チャネル共通のルール

過去のチャットで指示されたことです。チャネルを問わず守ります。

### 担当範囲
- マーケティングで持つのは、公式EC（Shopify）・ブログ・広告・SNS・LINEです
- Amazon・楽天・Yahoo!・量販・ディストリビューター・法人営業の数字は、それぞれの担当が決めます。分析で参照はしますが、こちらで目標や施策を決めません

### アウトプット（シート・レポート・ダッシュボード）
- **内部都合の文言を入れない。** 「こちら都合の情報」、作業メモ、チャットの経緯を前提にした説明、設計書のようなものは、他の人が読んでも分からないので載せない
- **必要のないものを何でも載せない。** 運用しやすさ、管理のしやすさ、進捗の見やすさを先に考える
- **見て直感的に判断できる形にする。** 表だけでなくグラフを入れる。何をどこで判断するかが分かる並びにする
- **既存のシートのデザインに寄せる。** KPIシートなら「KPIデータ」タブの色・行の並び・見出しの作りに合わせる

### 進め方
- 決まっていないことを、先に完成形として出さない。判断が要るところは一つずつ確認する
- 同じ指摘を二度させない。受けた指摘は、該当するスキルやチェックリスト、このメモに書き残す
- 自動で書き込む仕組みは「表示専用」を基本にする（書き換えできる自動化は事故のもと）
- CZURの作業として行ったタスクは、Hakoの「CZUR」プロジェクトに登録して完了まで管理する
  - https://hako.magnet-hako-todo.workers.dev/#/project/old%3Ap%3ACZUR

### 期間の数え方
- 期は10月〜翌9月です。今期＝2025年10月〜2026年9月、来期＝2026年10月〜2027年9月
- 前年比較は、前の期（2024年10月〜2025年9月）と比べます
- セールは毎年4月・8月・12月です。前後の月の比較では、セールの影響を必ず考えます

## メモの更新ルール

- 各チャネルのチャットは、作業の区切りで、自分のメモの「現在の状態」と「未決事項」を更新します
- 数字や決定事項には、決まった日付と元のチャット名を添えます
- PMチャットは、各メモの「現在の状態」「未決事項」「期日」を読んで全体をまとめます
