# 💬 CZUR｜LINE

公式LINE（Lステップ）の配信、クーポン、追いかけ配信を持つチャネルです。

## 前提

### 数字（9/28時点）
- 友だち（配信対象）は約2,500人
- 直近の配信の開封率は10.9〜12.0%。開封した人の約4割がタップしている
- セール以外の配信では、直接の購入がほとんどない（2026年のセール外の配信4本で、157セッション・購入1件）
- 一方でLINE全体では売れている。8/24以降の注文32件のうち7件がLステップ経由で、9月は5件・¥234,370。多くは友だち登録クーポン（CZUR10）を使い、ステップ配信やリッチメニューから来ている
- LINE登録時のアンケート「知ったきっかけ」（2026年8月、回答412件）：Instagram 221件（54%）、Google検索 71件（17%）。Instagramには Meta広告から来た人も含む

### 配信のルール（分かったこと）
- **浅い情報の配信は刺さらない**
- 動画は外部のX・InstagramのURLではなく、LINEの動画メッセージで送る。リンクは商品ページの1本だけにする（動画リンクが商品ページへの流れを奪っていた）
- 他の方の動画（まるさん、harupiさん など）を使うときは、二次利用の許諾が必要
- 高額品は当日に買われないことが多い。成果は配信の7〜14日後まで見る
- 購入前の不安（送料、支払い方法、保証、届くまでの日数）に先に答える配信が候補

### 計測
- Lステップの「サイトCV」は出ない。Shopifyの注文完了ページにLステップのCVタグが入っていないため
- 当面、配信の数日後の購入は、Shopifyの参照元（lstep）で追う
- タグを入れるなら、Lステップの「JS・リダイレクト設定」からタグを取り出し、Shopifyのカスタムピクセルに入れる
- LステップのMCPは、G-POWERのアカウントにしかつながっていない（CZURのURL別クリック数は取れない）

### 関連するページ
- LINE追加用LP：`/pages/fancy_campaign`、`/pages/fancy_campaign02`（EC分析からは除外する）
- ブログのLINE誘導URLは、スプレッドシートで発行済みのものを使う
