# ✍️ CZUR｜ブログ・SEO

公式ブログ（https://czur.jp/blogs/featured-articles/）の記事制作・リライト、GSC、ブログの効果測定を持つチャネルです。

## 前提

### 進め方
- 記事制作とリライトは、リポジトリのスキル `czur-blog-writer` に沿って進める（Phase 0〜3、リライトはPhase R0〜R3）。各Phaseの終わりに必ず浅野さん（または間崎さん）のレビューを受ける
- 製品の数値・機能は `docs/product-facts/` が正本。「未確認」とされている項目は本文で触れない
- 内部リンクは「記事管理マスタ」（KPIシート内）で実在URLを確認してから使う
- LINE誘導URLは、記事制作の前にスプレッドシートで発行済みのものを確認する。推測で作らない
- Shopifyには下書きとして入れるまで。公開ボタンは浅野さんが押す
- 効果測定は公開後2・4・8・16週。`/blog/actions` の測定メモは表示専用（自動で書き込み、手で書き換えない）

### 受けた指摘（繰り返さない）
- **冒頭や全体の構成を、競合の記事と意味もなく同じにしない**（何度も指摘されている。`editing-checklist.md` にも記録済み）
- 見出しのキーワード設計を毎回きちんと行う
- 「何を」電子化と呼ぶのかのように、言葉の関係を正確に書く（例：「契約書、レシート、図面、本。」が電子化なのではなく、それらを取り込むことが電子化）
- 表記は「全部」「一番」「〜の方が」に統一。「記事どうし」ではなく「記事同士」
- CZURの商品を紹介する箇所は、画像付きの従来の形にする
- 日本語の表現を直された箇所からは、何が足りなかったかを読み取って次に生かす

### ブログの成果の測り方
- ブログの成果は公式EC（Shopify）で測る。ブログ経由の注文は、購入前30日のどれかの訪問でブログ記事に着地した注文
- ブログ経由の注文の目標：来期 年124件（＝ブログ読者数 年101,380人 × 購入率0.122%）
- 先行指標：ブログ読者の翌月再訪率（今期4.5%）、記事から商品ページへの遷移率（今期10.6%）
- 4〜9月のブログ経由の注文は38件（月約6件）
- ブログに来た人の9割は初めての訪問で、翌月に戻るのは4.5%。記事で疑問は解けても、名前が残っていない
- 非ブランド検索のうち「紙類」がいちばん弱い場面。9月は本・書籍1,477、教科書272、写真171、書類191、図面49クリック

### 今期の方針と来期の打ち手（年間レビューより）
- 今期の方針：ブログ読者の回遊と接触回数を増やし、公式ECの売上につなげる
- 来期の打ち手（9/28 年間レビュー `ops/blog/annual-review-2025-10_2026-09.md`）
  1. 記事同士をつなぎ、欲しい情報を欲しいタイミングで届ける（製品ページ・LINEの製品診断・セール情報も含む）
  2. 「CZURの使い方」を記事と動画で増やす（検討中の人の使用イメージと、購入後のサポートを同じ記事で担う）
  3. 個人・法人ともに事例を増やす（活用シーンと導入実績の信頼で訴求）
- 法人向けの記事（不動産業など）にはB2B専用CTA（`https://czur.jp/pages/order`）を置く
- 現場の声：複合機では冊子の折り目、ホッチキス留め、小さい文字の書類で困っている。CZURとしてはETシリーズが答えになる
