# 🗂 CZUR｜全般

ほかのチャネルに入らないCZURの作業を受けるチャネルです。

## 使い方
- まず、どのチャネルの話かを確かめる。当てはまるチャネルがあれば、そちらで進めるよう伝える
- どこにも入らない作業（ちょっとした調べもの、資料の体裁、ツールの設定など）はここで進める
- 同じ種類の作業が何度も来るようなら、新しいチャネルを作るかどうかをPMチャネルで相談する
