# 🛒 CZUR｜Shopify

公式EC（czur.jp）の売上分析、購入プロセス、EC改修を持つチャネルです。Shopifyの担当は浅野さんです。

## 前提

### Shopifyのツリー（10/8・10/14 決定）
```
KGI  売上 ¥4,750万 ／ 実質利益 ¥1,353万
├ 注文数 827件 × 客単価 ¥57,400
│   注文数 ＝ 経路の合計（1件の注文は1つの経路にだけ入れる）
│   ├ ブログ経由（年124件） ＝ ブログ読者数 × 読者の購入率
│   ├ Google広告
│   ├ Meta広告
│   ├ LINE
│   └ その他（指名検索・直接・SNS・紹介など）
├ 購入プロセス  セッション × カート追加率 × チェックアウト到達率 60.5% × 決済完了率 40%
├ 利益    広告費率 年17%以内
└ 公式比率  計画の比率（年43.7%）を下回らない
```
- **経路の分け方**：購入前30日の訪問のどれかでブログ記事に着地していたら「ブログ経由」。それ以外は購入直前の流入元で分ける（直接の訪問は飛ばして、その前の流入元を見る）
- 広告の運用判断（ROAS・CPA）は各広告の管理画面の数字で行う。管理画面の数字は経路が重なるので、ツリーの合計には使わない
- KOL動画広告の費用はShopifyの広告費に入れない（送り先が全販路なので、マーケ予算として別に記録）
- 注文数の計画は827件（売上 ÷ 客単価。通常月 ¥55,000、セール月 ¥61,000）。P/Lにあった年1,460件の計画は使わない
- 細かい指標は「P/L_2026→2027」の「★Shopify KPI」欄に置き、主要な項目だけ進捗サマリーに出す

### 押さえておく事実
- セールは毎年4月・8月・12月。2026年のサマーセールは8/15〜8/23
- 10月から後払い（GMOイプシロン）を入れた
- セール外は、定価のET24 Proが売れにくい
- 9月から決済完了率が落ちている（チェックアウトまで進んで買わない人が多い）
- 今期の実績：注文568件、客単価 約5.4万円、公式比率 44.0%

### 9月の売上低下（10/5の調査）
- ET24 Proが8/27〜9/17に公式で在庫切れ。その間もモールでは買えた
- ET24 Pro・ETMAXの台数は、公式 -7台、楽天・Yahoo! +9.5台でほぼ見合う。3販路の合計は5・6月と同じ水準
- 見立て：セールの条件より「公式で買えなかった3週間」が効いた
- レポート：`ops/analytics/sales-decline-2026-10-05.md`

### EC改修の方向（8/24）
- 目指すもの：UI/UX（使いやすさ、情報の見やすさ、決断のしやすさ、購入のしやすさ）、回遊率を上げた先の滞在時間、SEOの評価向上
- 分析では、LINE追加用LP（`/pages/fancy_campaign`、`/pages/fancy_campaign02`）と、別の広告用の `/pages/starryhub03` を除外する
