# 📊 CZUR｜KPI・レポート

KPIツリーの設計、KPIシートの運用、月次集計、年間レポートを持つチャネルです。

## 前提

### ゴール（ブラさない）
**紙・本・書類を電子化したい、データ化したいと思ったときに、CZURが思い出される**

- KPIは今期からの積み上げで作ります。項目を前期と同じにする意味ではなく、前期の上に積む考え方です（10/8）

### KPIツリーの形（10/8 決定）
```
全体（C）  KGI: 全チャネル売上 ／ 制約: 利益率
│  全体で持つ指標: 指名検索・非ブランド検索（うち紙類）など、どの販路にも属さないもの
│
├ Shopifyのツリー（B）………… 浅野さん
│    └ ブログ経由の注文（A）
├ Amazonのツリー ………………… 胡さん
├ 楽天・Yahoo!のツリー ………… 劉さん
├ 量販 ……………………………… 宇田川さん
└ ディストリ・その他 …………… 森さん
```
- 一つの指標は一か所にだけ置きます。二か所に置くと合計が二重になります
- 施策（ブログ記事、広告、LINE、SNS）はツリーの外から指標を動かすものとして扱います
- 各販路のツリーは担当が作ります。マーケのツリーに販路の中身を分解して入れません
- SNSの表示回数は注文と計算でつながらないので、ツリーに入れません（施策の記録として扱う）

### 指標の定義（10/8 決定。詳細は「KW計測ルール」タブ）
| 指標 | 定義 |
|---|---|
| 指名検索 | GSC（czur.jp、ウェブ検索）の表示回数。検索語に「czur」とその打ち間違い（czer・szur・cuzr・crur・caur・cizur・cuzer・czus・czru・cezur）または「シーザー」を含むもの。製品名だけの検索（Fancy・Aura・Shineなど）は含めない |
| 非ブランド検索クリック | GSCのクリックのうち、ブランド語を含まない検索 |
| 　うち紙類 | 書類・領収書・レシート・名刺・契約書・請求書・帳簿・確定申告・ペーパーレス・図面・大判・A3・A2・地図・ポスターなどを含む検索（教科書系は除く） |
| 公式比率 | 公式 ÷（公式＋楽天＋Yahoo!）、売上で計算。目標は計画の比率（年43.7%）を下回らないこと（10/14） |
| ブログ経由の注文 | 購入前30日のどれかの訪問でブログ記事に着地した注文（Shopifyの定義に合わせる） |

- GSCのデータは16か月で消えます。前年同月比を出すため、毎月その月のうちに記録します
- GSC・GA4は、Macのセッションにあるサービスアカウントの鍵で取得します。クラウドのセッションからは取れません

| 非ブランド検索クリック | 年42,000（月2,900 → 4,100） |
| 　うち紙類 | 9月に月500 |
| Shopify | 売上 ¥4,750万、注文827件、客単価 ¥57,400、実質利益 ¥1,353万 |

| ガードレール | 利益率、Shopifyの広告費率（年17%以内） |

月別の目標は「KPI_2026→2027」タブにあります。

### KPIシートの構成（10/14時点）
- **KPI_2026→2027**：①進捗サマリー ②チャネル別の月次実績 ③マーケKPIの月別。B2の「対象月」を選ぶと累計と当月が計算される
- **KW計測ルール**：語の定義と計測のルールだけ
- **P/L_2026→2027**：63行目から「★Shopify KPI」（経路別の注文、購入プロセス、ブログ、客単価、実質利益、公式比率）
- **P/L_2026→2027_計画**：注文数は827件の定義（売上 ÷ 客単価。通常月 ¥55,000、セール月 ¥61,000）
- 黄色いセルが入力欄。達成率の色は100%以上が緑、80%以上が黄、80%未満が赤
- 売上・利益・Shopify売上は「CZUR_2026_チャネル全体計画」タブを参照する式
- 担当：Amazon 胡さん、楽天・Yahoo! 劉さん、量販 宇田川さん、ディストリ・その他 森さん、Shopify 浅野さん。マーケ予算は森さんが決める

### 年間レポート（2025年10月〜2026年9月）
- 読む人：社内のマーケと営業の皆さんと社長。担当名は出さない。KPIダッシュボードに載せる。数字の報告まで
- 数字の出典：全チャネル売上は「チャネル全体」タブ（¥432,992,913）、ブログはKPIシートを優先
- 楽天の広告費は ¥1,349,120。Makuakeは別の販路として扱う
- 購入率の打ち手：ECの全面改修＋広告のリマーケティング、多面的な配信で接触回数を増やす
