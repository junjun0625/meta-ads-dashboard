# 🧭 CZUR｜PM

CZURのマーケティング全体を見るチャネルです。各チャネルの進み具合をまとめ、優先順位と期日を管理し、チャネルをまたぐ判断を持ちます。

## このチャネルの役割
- 各チャネルのメモ（`docs/channels/*.md`）の「現在の状態」「未決事項」「期日」を読んで、全体の状況をまとめる
- 今週やること、判断が必要なこと、期日が近いことを、優先順に並べる
- 一つのチャネルで決めたことが、他のチャネルに影響するときに調整する（例：Google広告の不振とShopifyの売上、ブログとLINEの導線）
- 作業そのものは各チャネルで行う。PMチャネルでは、どのチャネルで何をするかを決める
- タスクはHakoの「CZUR」プロジェクトで管理する（https://hako.magnet-hako-todo.workers.dev/#/project/old%3Ap%3ACZUR）

## 全体の前提
- ゴール：紙・本・書類を電子化したい、データ化したいと思ったときに、CZURが思い出される
- KGI：全チャネル売上（制約：利益率）。KPIツリーの形は [kpi.md](kpi.md)
- マーケで持つのは、Shopify・ブログ・広告・SNS・LINE。他の販路は各担当（Amazon 胡さん、楽天・Yahoo! 劉さん、量販 宇田川さん、ディストリ・その他 森さん）
- マーケ予算は森さんが決める
- 期は10月〜翌9月。セールは4月・8月・12月

- KPIダッシュボード（https://czur-kpi-tree.vercel.app）は、GitHub経由ではなくMacの作業フォルダから直接Vercelに反映してきた

- 年間レポートはローカルにコミット済み（`104ee29`）だが、`vercel login` が切れていて未反映
- 進め方：`vercel login` → 本番とMacの作業フォルダの差分を一覧にする → 作業中の変更も出してよいか決める → 反映する
