# 🔍 CZUR｜Google広告

検索広告とP-Maxの運用、日次の取り込み、CPAの管理を持つチャネルです。

## 前提

### 対象のキャンペーン
- KPIに数えるのは `czur-shopify-Search`（検索）と `products-order`（P-Max）の2つ
- 名前に「Starry」を含むもの（StarryHub_指名/比較、Starry_課題解決など）、Web会議・プロジェクター・電子黒板用途は**対象外**。CZURのスキャナーではないため
- `CZUR_教育_ポテンシャル` の区分は「非ブランド」。対象外にすると3月の合計がKPIシートの凍結値とずれる
- 検索の「ET MAX」とP-Maxの「ETシリーズ」は別の区分で見る（キャンペーンが違うため）
- 7月ごろの「コーヒー器具メーカー palatti のケトル」のCVは、誤って計測されたもの。数えない

### 目標（今期の新しい目標を達成する前提。予算は追加分を含む）
| 項目 | 目標・基準 |
|---|---|
| 月予算 | 約19万円（年予算 ¥390万） |
| CPA | ¥8,900 |
| ROAS | 585%（最低400%） |
| 月のCV | 約21件ペース |
| 1月末の判断 | P-MaxのCPA上限 ¥12,000（確定ベースの値で判定） |

目標の詳細は「Google広告_目標」タブ。

### データの流れ
- 「CZUR_マーケ関連」シートの `Google広告_日次` に、Apps Scriptで毎日6:00〜7:00に自動で取り込む（MODE: daily）
- `Google広告_設定` タブのE列（区分）で、キャンペーン・アセットグループごとの区分を決める。「対象外」は月次の式やサマリーの合計に入らない
- `Google広告_ダッシュボード` で、毎週同じ順番で同じ問いに答える
- 9月のGoogle広告費は ¥167,496（検索 ¥60,844＋P-Max ¥106,653）

### 運用のルール
- 参考書・漫画は、スキャンがグレーなので広告で訴求しない
- M3000PROとStarryHubは、Merchant Centerで広告に表示しない設定にした（10/5）
- サイトリンクは新しく作った（スキャン動画やガイドはブログにしているなど、リンク先と識別子が古かったため）
- 構造化スニペットは見直す方向

## 現在の状態（2026-10-14時点）
悪化の原因は2つと見ています（元のチャット「Shopify売上低迷の原因調査」）。
1. **8/24以降のCVR低下**：セール後の落ち込みで、Shopify全体と同じ動き。ET24 Proの在庫が少なかった時期とも重なる
2. **9/21の週から、P-Maxのモバイルで質の低いクリックが急増**：クリックは週1,100前後から約2,000に倍増、CVは週0〜1件。クリック単価が下がっている（¥16 → ¥9）ので、ディスプレイ・YouTube・アプリなど安い枠に配信が広がった可能性が高い。直近28日のCVRはP-Max 0.05%、検索 0.53%

- ブランド検索（CZUR_メイン_ブランド）は安定。触らなくてよい
- P-MaxのCPAは確定ベースで ¥11,737（上限 ¥12,000 ぎりぎり）。直近28日は ¥18,492で、9/28週・10/5週が確定すると上限を超える見込み
- 10/5にP-Maxへ追加したアセットグループ「ET_主力_ET24Pro_ETMAX」（区分：ETシリーズ）は、9日間で ¥1,675しか配信されていない。このままでは10/19の評価で判断できない
